# Tilt Maze

Roll a marble through a random maze by tilting the badge, and race the clock to the gold tile.

## Usage

Hold the badge upright and tilt it to roll the marble. Press Select to recentre the tilt at your current angle, which also starts the next maze after a win. Each level is a new random maze and gets bigger up to level 4. Your best time per level is saved. Back exits.

Uses the onboard accelerometer. If the ball rolls the wrong way, recentre with Select while holding the badge the way you want to play.
